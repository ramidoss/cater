Three ways in

All three land the same component; they differ in how much structure survives the trip.

Route 1 · recommended

Paste the SVG code

  1. Hit Copy light SVG above.
  2. Open your Figma file, click empty canvas.
  3. Paste (⌘V / Ctrl+V).
  4. Select the group → right-click → Frame selection to make it a frame.

Fastest, and keeps every layer name. Figma parses SVG straight off the clipboard.

Route 2

Drag the .svg file

  1. Save c3-chat-work-canvas-light.svg from the chat.
  2. Drag it from Finder/Explorer onto the Figma canvas.

Same result as Route 1. Use it if the clipboard misbehaves in your browser.

Route 3

Import the live HTML

  1. Install the html.to.design plugin in Figma.
  2. Point it at the variants gallery URL.
  3. Import the C3 section.

Gives you auto-layout frames instead of static groups, but re-interprets the styling — expect cleanup.

Once it's in

A few things worth doing before you build on it, because SVG can't carry them across:

Structure

Frame it, then auto-layout

Frame the top group at 1160 × 680, then rebuild the chat rail and table rows as vertical auto-layout — the turns and rows are already evenly spaced (18px gaps, 38px rows), so it converts cleanly.

Components

Componentise four things

Chat turn (You / Agent variants), table row (default / top-performer variants), button (primary / ghost), and the chip. That covers every repeated element in the panel.

Corners

Re-round the rail

The rail's bottom-left corner is baked as a vector path so the card corner reads correctly. Replace it with a rectangle plus corner radius if you want it editable.
